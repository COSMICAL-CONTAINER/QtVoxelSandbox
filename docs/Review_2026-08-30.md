### #4 `b7fcb1c` (t944) `anchorFree` 一职两用——一次"受阻但未判上坡"的子步会永久打开逃逸豁免，上坡穿墙在坡底死端几何下间歇性复活

  ```cpp
  else {
      const bool uphill = ... cartRailGradient(...) && grad > kCartSlopeGradMin;
      if (uphill && anchorFree) { clampRailMoveToFree(...); break; }
      anchorFree = false;      // ← 非上坡受阻也翻假，重叠位保留

  ```
