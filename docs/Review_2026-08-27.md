## 五、 Lessons（供 lessons-learned 参考）

1. **QML ↔ C++ 契约面必须进探针**：#1 的 C++ 直调探针测不到 Q_PROPERTY 缺失（同 review26 #4 TapHandler 修饰键教训的 Q_PROPERTY 版）——凡 QML 消费的新属性，源码钉应包含 Q_PROPERTY 存在性。
2. **「同构先例」迁移要整段对照**：#3/#10 漏抄仙人掌先例的 Y 界定半边——迁移判据族时先列出先例的每个条件再逐条勾稽，注释声称 same shape 的地方恰是最容易漏的地方。
3. **锚与 drag 不可混用是 Qt Quick 硬约束**：#2 的注释作者知道机制但没有实现摘除——QML 位置接管类改动需要一条「首次交互断绑定」的实测冒烟（拖动 1px 断言位置变化）。
4. **权威迁移要扫「隐式液面/几何消费方」**：#6/#15 的睡莲两处都是按满格水面校准的隐式消费方——改全局常量时 grep 的不只是新权威函数名，还有按旧值标定的魔法偏移（1.0、1/16、+0.35 类）。
5. **修复提交的「覆盖面声明」要全链 grep 验证**：#5（雪球/蛋）、#13（粒子族）都是修复声称「全仓清点/四条路径」但清单不完整——声称封闭 exploit 的修复应把同族入口全部枚举进探针。
