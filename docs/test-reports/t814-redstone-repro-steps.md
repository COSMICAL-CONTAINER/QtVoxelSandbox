## 0. 前置核对（防陈旧 exe —— 必做）

本项目已出现 5 次「用户跑的是旧 exe、代码早已修复」的误报。复测前先核版本戳：

1. 启动游戏，**主菜单右下角小字**：形如 `2026-08-24 15:30 @ c9119c3`（构建时间 @ git 短哈希）。
2. 或进入存档按 **F3**，调试屏第二行 `build: ...` 同源。
3. 该哈希必须 **等于或晚于** 仓库最新 commit（`git log -1 --oneline` 的哈希）。不一致 = 陈旧 exe，
   请重新 `cmake --build build` 后用 `build/` 下的 exe 复测。

## 1. 三条防误判设计语义（先读，防把设计当缺陷）

| 现象 | 结论 |
| --- | --- |
| 发射器**空库存**时通电无任何动作 | **设计**（t607：玩家放置的发射器空库存 = 陷阱解除，不 fallback 射箭） |
| 拉杆**保持扳开**，发射器只射一次不连发 | **设计**（t689：通电上升沿触发一次；稳定通电不重复） |
| 拆掉拉杆后 **2 秒内**重新搭上，发射器不射 | **设计**（per-dispenser 2s 冷却闸） |

**装填方法**：右键发射器 / 投掷器方块打开装填面板，把物品从物品栏放入槽位（箭 / 雪球 / 鸡蛋 /
任意物品均可；投掷器对全部物品一律只「投」出掉落物）。

## 2. 场景矩阵（每源 × 每器件，最简搭建）

> 通用规则：先放**器件**并装填 / 就位，**最后**激活源（贴合放置的源一旦放下立即生效）。
> TNT 引信默认约 5 秒后爆炸（请远离或站在防爆位置观察）。

### 场景 1：拉杆 → TNT（最简）

1. 平地放一个 TNT 方块。
2. **贴着 TNT**（四侧任一）放一个拉杆，立即扳动（右键）。
- **预期**：TNT 方块消失 → 出现白色闪烁的引信实体（轻微跳动）→ ~5 秒后爆炸成坑。

### 场景 2：红石块 → TNT

1. 平地放 TNT，旁边留一格空位。
2. 在 TNT **直接相邻**的空位放红石块。
- **预期**：红石块放下的瞬间 TNT 即被点燃（同场景 1 后续）。
- 红石块是**常通源**，放下 = 永久供电，无法关断（要停只能拆 TNT）。

### 场景 3：红石火把 → TNT

1. 地上立一根红石火把（火把附着在地面上）。
2. 在火把**侧面直接相邻**的位置放 TNT。
- **预期**：TNT 立即点燃。
- 注意：把火把贴在 TNT **本体**上属于「附着物」场景，不是供电复现的正解；火把应立在地上、TNT 贴火把。

### 场景 4：红石粉链 + 拉杆 → TNT（粉传导）

1. 平地直线铺 **1–15 格红石粉**，一端尽头放 TNT。
2. 粉链另一端**贴着**放一个拉杆并扳动。
- **预期**：粉逐格点亮传导至 TNT → TNT 点燃。
- 粉最长传导 15 格（第 16 格起衰减为 0，这是机制而非缺陷）。

### 场景 5：红石块 → 发射器（装填箭）

1. 放一个发射器，**右键打开装填面板**放入一组箭。
2. 发射器任一侧面直接相邻处放红石块。
- **预期**：一支箭从发射器**朝向面**射出（可命中生物造成伤害；嵌入方块后玩家可拾取）；面板里箭 -1。
- 发射器放置时**排出口面朝玩家**（同熔炉 / 箱子放置朝向——放置时对着你的那面就是排出口，箭朝你
  这侧射出；要朝别的方向射请背对目标放置）。投掷器同此规则。

### 场景 6：拉杆 + 粉链 → 发射器

1. 发射器装填箭，正面朝向空旷方向。
2. 从发射器**背面或侧面**引 1–15 格红石粉，末端贴一个拉杆。
3. 扳动拉杆。
- **预期**：同场景 5，射一箭、库存 -1。拉杆扳回再扳开 = 再次射（间隔需 >2 秒冷却）。

### 场景 7：红石火把 → 发射器

1. 发射器装填箭；地上立红石火把。
2. 发射器任一侧**直接相邻**于火把。
- **预期**：立即射一箭（火把常通 → 通电瞬间为上升沿，触发一次；之后保持通电不再射，见设计语义表）。

### 场景 8：拉杆 → 投掷器（装填物品）

1. 放一个投掷器，右键装填任意可堆叠物品（如红石粉一组）。
2. 贴着投掷器放拉杆并扳动。
- **预期**：一件物品从投掷器朝向面**弹出**成掉落物（掉在地上可拾取）；面板库存 -1。
- 投掷器对箭也只「投」不「射」（箭作为掉落物弹出，机制等价原版 1.0 投掷器语义）。

### 场景 9：红石粉链 → 投掷器

1. 投掷器装填，背面引粉链（1–15 格），末端拉杆。
2. 扳动拉杆。
- **预期**：同场景 8。

### 场景 10：沿 / 冷却边界（防「怎么不射了」误判）

1. 复用场景 5 的机器（红石块贴发射器，已射过一箭）。
2. 拆掉红石块，**立即**（2 秒内）放回。
- **预期**：**不**再射（2 秒冷却闸）。等 2 秒以上再拆 / 放，才会再射一次。
3. 保持红石块供电不动，围绕机器做任何其它红石操作。
- **预期**：不再射（稳定通电无新上升沿）。

## 3. 日志判别（无反应时用）

游戏日志写在 `logs/voxelsandbox.log`。点燃 TNT 时 World 层会打一行：

```
vo.red: power TNT at <x>,<y>,<z>
```

| 观测 | 含义 |
| --- | --- |
| 日志有 `vo.red: power TNT` **且** TNT 被点燃 | 全链正常 |
| 日志有该行 **但** TNT 没反应 | 消费端问题（firePowerTnt 链）——请回报此现象 + 版本戳 |
| 日志**无**该行且 TNT 没反应 | World 电力层问题（源 / 传导 / 接收判定）——回报搭建截图 + 版本戳 |
| F3 / 主菜单看不到 build 行或哈希过旧 | 陈旧 exe，先重新构建 |

（发射器 / 投掷器无同类专属日志行，判别走场景矩阵的现象本身。）
