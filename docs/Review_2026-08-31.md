## 一、中危（建议尽快修复）

### #28 `a5f09af`（批 B #4 修复）采样失联回退分支未豁免入点嵌入车——嵌入车 + 失联子步 = 每 tick 回退清速，逃逸豁免「防永久冻结」承诺在该路径失效

- **问题**（主审逐分支核实 `minecartmanager.cpp:799-824`）：#4 拆分后的受阻三分法里，`uphill` 分支正确保留了嵌入豁免（`:811-816` `haveFreePos` 为假时带重叠继续推进），**但 `!sampled`（采样失联）分支无条件回退 + 清速 + break**：
  ```cpp
  } else if (!sampled) {
      c.pos.setX(preX); // 梯度失联 → 回退本子步起点（上一提交位）：重叠位不保留
      c.pos.setZ(preZ);
      c.speed = 0.0f;   // 受阻即停
      break;
  }
  ```
  该分支不看 `embeddedAtEntry`。而函数头契约（`:702-704`）明写「入点位即重叠 = 嵌入车 → 本 tick **全程**逃逸豁免（允许带重叠移动直至脱出，**防永久冻结**）」——`minecartmanager.h` stepCartAlongRail 段新注释同样先写「入点嵌入 → 全 tick 允许带重叠移动直至脱出」、又写「梯度采样失联的受阻子步回退本子步起点」，两句在「嵌入 × 失联」组合下互相矛盾，代码实现的是"回退赢"。
- **机制推演**：入点嵌入的车（`haveFreePos=false`）每 tick：入点探测嵌入 → 子步位移提交 → 受阻且 `cartRailGradient` 失联 → 回退 + `speed=0` + break。玩家推车（`pushEmptyCart`）/ 动力轨喂速每 tick 被整段吞掉——**车永久冻结在重叠位**，直到玩家拆掉重叠方块（blocked 变假后恢复）。修复前的形态（`a5f09af^`）该组合下车持续带重叠移动直至脱出（豁免生效）——这是 #4 修复引入的行为回归面。
- **可达场景**（两个自然入口）：
  - 静置车停在**死端前一格 / 拐角垂直臂旁**（前探针列无轨 → 采样恒失联，`:443-444` 自列的失联几何），玩家往车位里放一个方块（或落沙掩埋，`:702-703` 自列的嵌入入口）→ 推车推不动。
  - 批 B 自己的 (c) 腿几何（坡底后轨被拆 → 后向采样失联窗）+ 车位被方块嵌入 → 同样冻结。
- **旧穿墙连锁不会因修复复活**：连锁根因是**非嵌入**车的标志污染（失联翻 `anchorFree=false` → 重叠位保留 → 下 tick 入点被污染成嵌入）。嵌入车在旧版本就走豁免路径；给失联分支补 `haveFreePos` 门只是把豁免口径补齐到第三个受阻子类，不触碰非嵌入车的回退语义。
- **修复建议**（一行门，与 uphill 分支同口径）：
  ```cpp
  } else if (!sampled) {
      if (haveFreePos) {          // 非嵌入：回退 + 清速 + 停
          c.pos.setX(preX); c.pos.setZ(preZ);
          c.speed = 0.0f;
          break;
      }
      // 入点嵌入 → 逃逸豁免延续（带重叠推进直至脱出），同 uphill 分支
  }
  ```
  同步修 `.h`/函数头两处注释的矛盾表述（失联回退注明「仅非嵌入」）。
- **探针为何没抓住**：P-r0830B(c) 腿的 rig 是**非嵌入**车（撕裂后轨测穿墙）；P-t944 六腿也无「入点嵌入 × 失联」组合腿。建议补一条嵌入腿模板（见 §五-1）。

## 二、低危（择机修复）

### #29 `a5f09af`（批 B #8）静置闸预筛在边界几何下与直接采样不等价——「行为等价」注释失实（方向保守：旧翻向溜坡 → 新停驻）

- **问题**（主审对拍采样几何）：预筛（`minecartmanager.cpp:992-1008`）只查**本格 4 邻** ±1 层（fwd/bwd/perp 四组三高探针），但梯度采样探头是 `pos ± 0.25·行进向`（`kCartPitchProbe=0.25`，`.h:526`）——静置车只有**垂直轴**被向心收敛（t770②），行进轴位置可停在格内任意处；车停在格边 0.25 内时前探头越入邻格，而邻格的 `railRiseAt` 坡面由**该格自己的邻居**（含 2 格外的 ±1 轨，`.cpp:403-420`）供坡——预筛看不见 2 格外轨。
- **数值**：车 fx∈[0.75,1.0)、邻格起坡（其 +1 轨在 2 格外）时，旧直接采样 grad = 邻格 rise/0.5 ∈ [0.5, 1.0] —— 远超阈 `kCartSlopeGradMin=0.1`（`.h:561`）→ 旧版判「坡」翻向溜坡；预筛 maySlope=false → 跳过采样 → 新版停驻。
- **定性**：行为差只在「停驻位置落在格边 0.25 带 × 坡道起点恰在邻格」的组合里出现，且新行为（车心在平格上不溜）比旧行为（探头沾坡即整车翻向溜）更保守、更符合直觉——**登记或修注释均可接受**，但 `:992` 「行为等价，口径 = 采样窗 ±1 层」的承诺表述失实，留着会误导后续调参者。
- **修复建议**（二选一）：(a) 最小——注释改为「格心区（行进轴 |frac−0.5| ≤ 0.25，探头不出格）行为等价；格边带保守化（跳过采样不溜坡）」，登记取舍；(b) 保持等价——预筛加一条「行进轴车位在格边 0.25 带内 → 不早退照常采样」（平地常态车在格心，性能收益不变，边界几何还原旧行为）。
