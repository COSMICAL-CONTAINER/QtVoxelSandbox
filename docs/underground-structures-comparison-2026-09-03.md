## 2. 逐结构 MC 1.0 中性对照与差距

对照基线取 MC 1.0（正式版早期）该类结构的通行机制认知，按「形态 / 频率 / 内容」三轴列差距。**总评：五结构骨架齐备（影子成立），不像的部分集中在「形态随机度不足、房间类型单一、内容位密度偏低」三点。**

### 2.1 地牢房（dungeon）

MC 中性描述：地下小型封闭石室，内空尺寸随机（约 5-7 格见方、净高 3-4）；圆石与苔石混砌（地板苔斑常重于墙面）；中央刷怪笼（敌型仅限数种近战/远程常见敌怪，按权重抽取）；战利品箱 1-2 个、落位随机（常贴墙角）；箱内「常见材料堆量 + 稀有件单件」。

| 轴 | 差距 | 状态 |
|---|---|---|
| 形态 | 内空恒 7×7 vs MC 随机 5-7 见方 | **t995 首批已修**（W/Z hash 独立位取 5/7） |
| 形态 | 墙材圆石+石头混排 vs MC 圆石+苔石混砌（旧注释「工程无苔石」已失效 —— t486 起工程有 MossyCobble） | **t995 首批已修**（地板 50% / 墙顶 25% 苔率） |
| 内容 | 恒 1 箱定角 vs MC 1-2 箱随机位 | **t995 首批已修**（对角角位 ~50% 二箱） |
| 形态 | 房间恒整轴对齐矩形 vs MC 偶有与洞穴相交的残缺房 | 保留（工程「洞穴穿墙暴露」机制已有同等观感，不修） |
| 内容 | 笼型含爬行者 15%（MC 地牢笼无此类） | 保留（工程有意扩展，登记不修） |
| 频率 | 24 格网格 10% ≈ 中等稀有，MC 量级相当 | 保留 |

### 2.2 废弃矿井（mineshaft）

MC 中性描述：地下连通巷道网络，交叉处常有小洞室；巷道 3 宽 3 高、木质支架成对（顶梁+立柱）间隔支撑、地板中间铺连续铁轨；蛛网成簇出现在支架角；**洞穴蜘蛛刷怪笼小室**（密集蛛网环绕）是该结构标志内容；**沿巷道散布多个储物箱**；整体无光源（昏暗）。

| 内容 | 全矿井仅 1 箱（交叉洞室角位）vs MC 沿巷道多箱散布 | 批次 2（巷道段位 hash ~15% 落侧箱） |

## 3. 首批修正清单（本批已落）

三项全落 `placeDungeons()`（地牢是「影子感」最重、探针最好钉的结构；修完即从「恒 7×7 圆石+石头单箱」变为「随机见方苔石混砌 1-2 箱」的 MC 观感）：

1. **苔石混砌（P-t995a）**：`wallBlock` 从 Cobble+Stone（25% 石头）改为 Cobble+MossyCobble，地板苔率 50% / 墙顶 25%（MC 地牢地板苔斑更密的方向性）；删除「工程无苔石」失效注释。
2. **内空随机见方（P-t995b）**：内空 W/Z 各按 `r` bit28/bit29 独立取 5 或 7（与既低位概率/抖动/cy、bit20-27 笼型位零耦合）；margin 基准改 `kRoomWMax`。
3. **每间 1-2 箱（P-t995c）**：必放原点角箱，~50%（`r` bit30）对角角位 `(roomW-1, 1, roomD-1)` 再放一箱；同 `ChestStateDungeonFlag` → 首开各自独立填 `dungeonChestPool`。

探针：共享 rig（t786 同款 5 seed × 128×128×64 世界池，地牢笼锚定逐房采样：笼顶二层量游程得内空、净样统计苔/圆石计数与箱数），三条独立 PASS 行：

- **P-t995a**：池内地板/墙顶双材质齐备 + 地板苔率 > 墙顶苔率（叉积式方向断言）+ 源码钉（旧 Cobble+Stone 形态绝迹 + 新行 verbatim）；
- **P-t995b**：净样 W/D 全 ∈ {5,7} + 池内 5 与 7 均出现 + 源码钉（bit28/29 行）；
- **P-t995c**：每净样 1..2 箱 + 双箱房第二箱必在对角 + 源码钉（bit30 行）。

回归面：placeDungeons 参数改动只影响地牢房本体（网格/概率/y 带未动）；t786 地牢笼型分布探针（位域 bit20-27 未动）、t393 战利品链、t759 要塞净空、t484 矿井轨探针全不动。矩阵 416 → 419。
